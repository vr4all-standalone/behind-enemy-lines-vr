A separate P2-first run confirms that the fields follow native player identity: P2 becomes 2700 while P1 stays zero, then P1 joins later.

In service, `0x5a883d` is the actual selected page and `0x5b4b64` its phase; Gun Calibration is page 3, phases 3/4 are P1 stops and 5/6 P2 stops. Player availability is normalized for ownership/model visibility; no measured health percentage is claimed.

`native/game_state.h` now verifies twelve literal original BEL instruction/address words before reading these fields. It also validates the observed original settings pointer `0x5a85e8 → 0x5a85f0`; native start/continue prices are bytes at settings +15/+16 and free play is the native `0x5a8810` flag. Wrong game fingerprints and incomplete boot fail closed. Native lifetime negative/zero distinctions are supported by the original credit code; actual death/continue play is still untested.

BEL's native credit acknowledgement occurs after coin release/debounce, about 0.25 seconds in the trace. The inherited fixed 0.14-second Start delay was therefore unsuitable. The production input policy now waits for the actual native credit acknowledgement, retains a quick A/X tap and emits a full Start pulse after acknowledgement; available credit/free play avoids adding a gratuitous coin. Higher coin/start prices remain native: a request contributes at most one coin; additional credits require fresh requests. New tests prove this measured timing and require a fresh trigger/Missile after native intro-to-world transitions.

Native shots, gun calibration storage/inverse and weapon IDs remain unverified. Their readers still fail closed; no physical trigger or activation field is used as an accepted-shot counter.

Native unreachable borders/HUD targets fail closed. Private capture verification inverts7,744 visible points with maximum error0.000261757 native pixels.

Independent review identified stale yaw-dependent calibration and queued firing at the XR-to-native handoff. Both were reproduced through the actual `SharedRuntime` latch. Physical hands/aim intent now travels with native session/player ownership and is resolved against freshly read calibration immediately before delivery. Both hand layouts, P1/P2, invalid→valid recovery, service entry/exit and stale-session/player transitions pass the production runtime regressions. Runtime ABI is now0x42454c04.
