# Behind Enemy Lines VR design

Implement the original 1997 Sega / EPL Productions arcade game `bel` as an independent Quest 3/3S and Windows OpenXR port. This is one of the three Model 2 games the user explicitly authorized in parallel. Source is isolated here; compiler, research and private media live under `D:/VR4ALL-BEL-Build`. Do not publish, install or launch on a headset in this run.

The pinned primary source is MAME 0.289 commit `f34f02505e32c1993c6a782b6814232cbfc74e36`. `bel` is Model **2C**, using i960, TGPx4 and SCSP audio. Its native status is `MACHINE_NOT_WORKING`; compilation is not proof of native or VR playability. `bel` inherits Gunblade's unreversed eight-bit ADC limits and trigger bits, swaps the Test and Service bits, and adds independent P1/P2 Missile buttons. The ADC channel order is P1 X, P2 X, P1 Y, P2 Y. No reload or VC2 serial gun protocol is to be invented.

Reuse selected, attributed common Model 2 renderer, OpenXR, audio and purple VR4ALL UI modules from the local Gunblade host. Preserve native geometry before clipping, real per-eye projection/head movement, original audio and tiles. Keep game-specific cabinet, state and calibration adapters independent. No Gunblade addresses, player acknowledgements, shot trackers or native weapon model IDs establish BEL state. Unknown state and native feedback fail closed. Until original media and measured gameplay evidence are available, the host must explicitly report its development/evidence limits.

Required full-port behavior remains the accepted architecture: original stereo world and audio; tracked guns; native P1/P2 start/join/continue with fresh-input guards; reversible P1-left/P2-right defaults and solo hand transfer; persistent purple VR4ALL options; native service/calibration; automatic main gun plus Missile where verified; native weapon and accepted-shot effects only with measured evidence; recenter/pause/quit; independent media-free packages. Use `com.vrlightgunhub.bel`, `bel_xr` and `bel_audio` identities. Software tests, host compilation, engine build, ROM boot, headset rendering and actual play are reported separately.

Original media must match the manifest by size, CRC32 and SHA1. Read original archives without modifying them; stage any canonical media privately on D:. Do not download commercial data. Packages exclude media, captures, NVRAM, settings and keys. No source or release publication is authorized.
