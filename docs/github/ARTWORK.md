# Banner artwork

The right panel uses a crop of Sega's original *Behind Enemy Lines* promotional flyer, archived as [Behind Enemy Lines arcade artwork](https://bdjogos.com.br/jogo.php?id=20699) by BD Jogos. Original game artwork and trademarks belong to Sega.

The left panel follows the existing VR4ALL dark-grid title layout. The flyer is archival artwork, not a screenshot of VR gameplay. No AI-generated game characters or scenes were added.
