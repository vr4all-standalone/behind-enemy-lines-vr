# Behind Enemy Lines VR

Original Sega / EPL Productions **Behind Enemy Lines** (`bel`, Model 2C) for Quest 3/3S and Windows OpenXR. This is an unpublished development port. The user has confirmed Quest 3S gameplay, shooting, scale, audio, haptics and recoil on the preceding candidate. The latest HUD/reticle/recoil refinements still need physical acceptance; Windows OpenXR play remains untested.

The implemented foundation includes the independent BEL cabinet adapter, main gun and Missile inputs, reversed Test/Service switches, player/hand transition guards, persistent purple VR4ALL settings and the shared Model 2 geometry/OpenXR/audio host. Native readiness, credit acknowledgement and independent P1/P2 activation have fingerprinted production readers and tests. Saved native calibration and the measured focus400 world aiming inverse have original-game capture checks. Invalid/virgin calibration, unsupported views and targets outside native gun reach suppress firing. A usable original player gun model has not been identified. Main-gun feedback uses verified native firing acknowledgements; Missile-specific feedback remains unverified.

Fresh settings use the user's accepted Wider-view configuration: world size **0.830**, panel distance **1.8 m**, view width **65 degrees**, Wider view on. The In-game reticle defaults to **35% minimum**, **145% maximum**, and **10.0 m** shrink distance; HUD size defaults to **120%**. Screen mode retains **0.100**. Each mode remembers its own World size; valid existing saved settings are preserved. Reset to defaults applies this profile.

All 31 original ROM payloads are required in `bel.zip`. No CHD or separate billboard firmware is required by the pinned MAME BEL definition. No game data is distributed. The Android app uses `com.vrlightgunhub.bel`; app-owned media belongs in `/sdcard/Android/data/com.vrlightgunhub.bel/files/roms/`. Windows uses a separate `roms` folder. Keep settings/NVRAM separate from original archives.

Builds never install to a headset or publish. GitHub publication and headset testing require separate overseer coordination.

During native gameplay with Wider view on, the large bezel and green aiming grids are removed. The original health, fuel and ammo status remain. Laser targeting ignores native HUD geometry and selects the nearest actual 3D world surface; a clear miss extends into the world instead of stopping at the old panel plane. Wider view off restores the full original foreground and HUD geometry, without cropping. Native boot/title/service screens remain intact.

The original per-player firing counter now drives controller haptics, tracked-gun recoil, muzzle flash and smoke; blocked input does not create a local firing event. Wider-view sky uses the original background by view direction instead of a nearby card. The guarded GPU path skips duplicate CPU-world drawing only in verified gameplay, with original rendering retained for boot/service/capture and incomplete frames.

The complete bottom ammo band is retained, including the yellow/green sections that grow outwards. BEL's original live circular reticle mesh, without its long screen rulers, appears at the laser's world hit with stereo depth. Recoil uses Teraburst's shorter 80 ms pulse without changing native firing cadence. See [current validation](docs/reticle-hud-feedback-report.md).
